协作机制

共享 Memory，
让 Agent 真正合作。

三个 Agent 通过中央状态层传递信息 — 这是多智能体协作的核心。

从输入目标，到收获洞察。

每一次 Agent 调用都会读写共享状态，下一个角色基于完整上下文继续工作。职责隔离让每个角色的 Prompt 更专注，结果更精准。

  • 1 用户输入目标"7 天内复习完线性代数"
  • 2 规划师拆解为任务树写入 shared_memory.tasks
  • 3 执行官每日推进读取任务 → 推送 → 写回进度
  • 4 复盘师生成周报读取所有事件 → 洞察 → 给出下周建议
完整能力

从一个目标，
到一段闭环成长。

定目标、拆任务、日执行、周复盘 — Yuki 把碎片化的成长行为收束成可持续的循环。

⌘  OBJECTIVE TREE

把"考研"变成今天可以做的事。

规划师基于 LLM 分析你的目标语义，生成具有时间锚点、依赖关系与优先级的任务树。可调节颗粒度 — 从粗略大纲到细致分解，由你决定。

⏱  DAILY PUSH

每日清晰的下一步。

执行官根据节奏推送当日任务，识别"卡了 3 天没动"的卡点，主动诊断原因 — 是任务过大，还是优先级错了？

∑  WEEKLY REVIEW

不只流水账，还有洞察。

复盘师读取整周事件，输出节奏图、瓶颈分析和下周建议。不是"你完成了 12 个任务"，而是"你周三总是低产，建议把硬任务移到周一"。

∮  SHARED MEMORY

透明的协作。

所有状态可见可审。你可以看到每个 Agent 写了什么、读了什么。

⌬  BYO API KEY

用你信任的模型。

支持 Anthropic Claude、OpenAI、DeepSeek。Key 仅存浏览器，零中转。

◐  OFFLINE FIRST

数据归你所有。

所有 Memory 存于本地，可随时导出 JSON。无云端绑定。

常见问题

关于 Yuki 的 几个问题。

Yuki 和 ChatGPT、Claude 有什么不同？

ChatGPT / Claude 是通用对话 AI，每次对话独立。Yuki 是产品 — 三个 Agent 各司其职，通过共享 Memory 持续协作。它记得你的目标、追踪你的进度、给你针对性的复盘。它不是聊天，是工具。

为什么是三个 Agent，不是一个？

受 MetaGPT 启发的多智能体协作范式：把"拆解 / 执行 / 复盘"三种思维模式分给三个独立 Prompt，每个角色更专注，输出更专业。单 Agent 经常在不同任务间切换得不够好，三 Agent 通过共享 Memory 解耦协作，质量更稳定。

我需要付费吗？

Yuki 本身完全开源免费，永久免费。LLM 调用费用取决于你的选择：内置 Demo 模式完全免费（脚本回复）；用 Anthropic / OpenAI / DeepSeek 需要你自己的 API Key（费用直接走你的账户）。我们不在中间抽成。

我的数据安全吗？

所有数据（目标、任务、活动）都存在你浏览器的 localStorage 里，Yuki 没有服务器，没有任何数据上传。API Key 同样仅存浏览器，直连 LLM 供应商。你可以随时导出 JSON 备份。

我能在公司 / 团队里用吗？

当前 v0.1 是个人版。多用户协作（合伙人模式 · 互相监督）规划在 v1.0。如果你想提前体验，可以 fork 项目自行扩展。

Yuki 这个名字是什么意思？

「ゆき · 雪」— 雪花的几何之美来自它的"自相似"：每个分支都是整体的缩影。三 Agent 协作就像雪花的形成，每个 Agent 都是独立专业的，但合在一起呈现完整的成长闭环。
