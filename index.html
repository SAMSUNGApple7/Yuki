协作机制

共享 Memory，
让 Agent 真正合作。

三个 Agent 通过中央状态层传递信息 — 这是多智能体协作的核心。

从输入目标，到收获洞察。

每一次 Agent 调用都会读写共享状态，下一个角色基于完整上下文继续工作。职责隔离让每个角色的 Prompt 更专注，结果更精准。

  • 1 用户输入目标"7 天内复习完线性代数"
  • 2 规划师拆解为任务树写入 shared_memory.tasks
  • 3 执行官每日推进读取任务 → 推送 → 写回进度
  • 4 复盘师生成周报读取所有事件 → 洞察 → 给出下周建议
完整能力

从一个目标，
到一段闭环成长。

定目标、拆任务、日执行、周复盘 — Yuki 把碎片化的成长行为收束成可持续的循环。

⌘  OBJECTIVE TREE

把"考研"变成今天可以做的事。

规划师基于 LLM 分析你的目标语义，生成具有时间锚点、依赖关系与优先级的任务树。可调节颗粒度 — 从粗略大纲到细致分解，由你决定。

⏱  DAILY PUSH

每日清晰的下一步。

执行官根据节奏推送当日任务，识别"卡了 3 天没动"的卡点，主动诊断原因 — 是任务过大，还是优先级错了？

∑  WEEKLY REVIEW

不只流水账，还有洞察。

复盘师读取整周事件，输出节奏图、瓶颈分析和下周建议。不是"你完成了 12 个任务"，而是"你周三总是低产，建议把硬任务移到周一"。

∮  SHARED MEMORY

透明的协作。

所有状态可见可审。你可以看到每个 Agent 写了什么、读了什么。

⌬  BYO API KEY

用你信任的模型。

支持 Anthropic Claude、OpenAI、DeepSeek。Key 仅存浏览器，零中转。

◐  OFFLINE FIRST

数据归你所有。

所有 Memory 存于本地，可随时导出 JSON。无云端绑定。
